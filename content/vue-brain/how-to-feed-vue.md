Vue answers from markdown files in content/vue-brain. One file is one topic.
Adding knowledge means adding a file, and nothing else.

The shape of a file:

    ---
    title: A plain title
    tags: [words, someone, might, actually, type]
    ---

    The answer, written the way you would say it out loud.

Three rules that decide whether she answers well:

1. Tags are how she finds a passage. Put the words a person would actually type,
   not the words you would file it under. "cost" and "budget" beat "commercials".
2. One file, one topic. A file covering four things scores badly against all four.
3. Write the answer, not a pointer to the answer. She paraphrases what is in the
   file. If the file says "see the pricing page", that is what she will say.

If no file scores above the confidence floor, she says she does not know it rather
than guessing. That is deliberate. A missing answer is a note to write a file.
