## The Core Question: What Keywords Should ROV Capture?

Before picking keywords, you need to know WHO is searching and WHAT they're thinking when they search. For ROV, there are two different mental states:

**Mental state 1 — Problem aware, not solution aware:**
> "Why am I not getting enough calls?" / "Why is my competitor showing up and I'm not?"
These people don't know they need SEO, a new website, or AI automations. They know they have a problem. GEO content targets these people.

**Mental state 2 — Solution aware:**
> "I need a web designer in Atlanta" / "I need someone to set up AI automations"
These people know what they want. They're comparing options. Traditional SEO targets these people.

ROV needs content for BOTH. But the GEO/problem-aware content is where the opportunity is right now because competition is low and AI search is growing fast.

## How to Prioritize (The Decision Framework)

When deciding which keyword to go after next, ask:

**1. Do we have proof?**
If yes → build the page now. Proof is our competitive advantage.
If no → build the proof first (do the work, then write about it).

**2. Is this what our ICP is actually asking?**
If an Atlanta HVAC owner would type it or ask Perplexity → yes.
If it only sounds like something marketers say → no.

**3. Is anyone else building this for Atlanta specifically?**
Check: search the term. If you see generic national results with no Atlanta-specific pages → opportunity.
If you see 10 Atlanta agencies with dedicated pages → harder to compete.

**4. Can we update it in 90 days with fresh data?**
GEO rewards freshness. Only build pages you'll actually maintain.
